## 1. 目标

把原来「一页一件事」的导航结构改成 MXU 式主界面：**左边任务链、右边连接 / 截图 / 日志三面板**，顶部给全局开始/停止，并常驻一条任务运行状态总览。

## 3. 关键设计取舍

1. **任务链不复制状态**：`MainViewModel.Tasks` 是唯一实例，导航「任务」页与主界面左栏、顶部工具栏三处绑同一个对象。否则「工作台加的任务任务页看不到」，或两边各自存一份队列。
2. **截图面板不另起抓帧**：直接用 `InstanceViewModel.PreviewSource`。预览泵的判据是「激活实例 + 已连接 + 窗口未最小化」，与页面无关，所以主界面能直接用实例页的同一路帧。
3. **日志面板轮询增量**：沿用日志页的思路（`LogBuffer.Version` + `SnapshotSince`），400ms 一次、界面只留 200 行、一次积压超上限整体重建。逐条订阅在长跑里会变成每秒上千次 UI 调度。
4. **折叠用行高而不是 `Expander`**：`PanelStateViewModel.RowHeight` 展开时是 `Auto`/`N*`，折叠时回落 `Auto` —— 内容 `Collapsed` 后这一行只剩标题栏，不会留一块空白，也不需要重排三份布局。
5. **总览放顶部而不是任务页**：任务页只负责「配置」，运行态属于全局信息，任何页面都该看得见。

## 4. 过程中修掉的真实缺陷

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 任务链已有 4 项，摘要仍写「队列 0 项 · 启用 0」，「开始」按钮始终灰 | `AddTaskToQueue` / `RemoveInstance` 只调 `RaiseCommandStates()`，它只刷新三个命令的 `CanExecute`，**不发 `TaskSummary` 与 `CanStartRun`**；以前摘要和按钮都在任务页内部，靠别的事件顺带刷新，没人发现 | `RaiseCommandStates()` 补发 `TaskSummary` + `RaiseRunStates()` |
| 连接失败时日志面板永远只有启动那一行 | 连接过程只写 `StatusText`，从不写日志 | `InstanceViewModel.LogConnect()` 在配置无效/未找到窗口/设备被占用/连接失败/异常/成功/断开七处落日志 |
| 「开始」按钮禁用时仍是高亮蓝底，看着像可点 | 自定义 `Background` 绕过了模板的禁用配色 | 加 `IsEnabled=False → Opacity 0.4` 触发器 |

## 6. 已知限制

- **面板折叠状态不持久化**：重启回到三面板全展开。要记状态得进配置（归 P6.2 起的设置项）。
- **面板顺序固定**：连接 → 截图 → 日志，暂不支持拖动换位。
- **顶部「开始」按的是任务页当前选中的配置组**：多实例场景下，若某实例绑定的配置组与任务页选中的不同，以任务页选中者为准。多实例下的「按实例分别运行」属 P7 多开深化的范畴。
- **日志面板只读**：不能过滤/暂停，需要时点「完整日志」跳到日志页。

## 8. 改版：对齐 MAA 的四页签布局（2026-10-27）

### 8.1 起因

第一版的「左任务链 + 右连接/截图/日志三面板」把运行期的辅助信息都堆在主界面，
和 MAA 的实际形态不一致：MAA 主界面只有任务，连接与截图在设备页，日志在工具里。
用户拿 MAA 截图对齐后确定了目标形态，本版按图重做。

决议（用户确认）：**顶部页签 = 一键长草 / 多实例 / 小工具 / 设置**，实时截图移到「多实例」下面。

### 8.2 结构变化

| 原 | 现 |
| --- | --- |
| 左侧 184px 导航 + 右侧内容 | **顶部页签行**（文字 + 选中下划线），左侧导航整体删除 |
| 主界面（`WorkbenchView`） | **一键长草**（`TasksView` 重做） |
| 任务（`TasksView`） | 并入「一键长草」，不再是独立页 |
| 实例（`InstancesView`） | **多实例**（含连接、实时截图、配置组） |
| 定时（`TimersView`）/ 日志（`LogsView`）/ 连接（`ConnectionView`） | 收进 **小工具** 左侧二级导航 |
| 设置（`SettingsView`） | **设置**（缓存 / 资源整理 / 关于） |
| 实例标签条（独立一行） | 并入顶栏右侧的实例下拉（省一整行高度） |

删除：`Views/Pages/WorkbenchView.xaml(.cs)`、`ViewModels/WorkbenchViewModel.cs`、`ViewModels/PanelStateViewModel.cs`。

### 8.3 一键长草的布局

```
┌──────────── 286px ────────────┬──────────── 右侧（*）─────────────┐
│ ☑ 任务名                    ⚙ │       以下选项为多任务共用           │
│ ☑ 任务名                    ⚙ │  实例    [下拉]                    │
│ …（卡片内滚动）                │  配置组  [下拉]                    │
│ ─────────────────────────     │  未连接（黄/红字，随状态变色）        │
│   ＋   │   全选   │   清空     │ ──────────────────────────────  │
├───────────────────────────────┤  常规设置 │ 高级设置（选中下划线）   │
│ 完成后 [无动作 ▾]              │  常规：当前任务参数 + 恢复默认/清空本组 │
│ ┌───────────────────────────┐ │  高级：全局选项 + pipeline_override │
│ │       Link Start!         │ │                                  │
│ └───────────────────────────┘ │                                  │
└───────────────────────────────┴──────────────────────────────────┘
```

- **任务行**：勾选框 + 名称（双击重命名）+ `×N`（同类多实例）+ 齿轮；左侧 3px 色条表示运行态（无/橙/绿/红/灰）。
- **齿轮**：点击把右侧定位到该任务（等价于选中行），不弹独立窗口——右侧本来就是参数区。
- **⊕ / 全选 / 清空**：⊕ 弹任务目录 Popup；全选置全部 `Enabled=true`；清空只取消勾选、不删任务（与 MAA 一致）。
- **完成后**：无动作 / 退出程序 / 关机。选「关机」二次确认；只在整轮 `Completed` 时触发，用户按停止或暂停不触发。
- **Link Start!**：空闲时整宽主按钮，运行中换成「暂停 / 继续」「停止」两个按钮。

### 8.4 顺带补的引擎侧能力

`TasksViewModel` 新增 `SelectAllCommand` / `DeselectAllCommand` / `EditItemCommand` / `AfterCompletionIndex`；
`SelectedRightTab` 从裸属性改成会发通知的属性（驱动常规/高级切换）；订阅 `InstanceWorkspace.CurrentChanged`
刷新「多任务共用」区的实例下拉。

### 8.5 调试参数变化

| ~~`--collapse 连接\|截图\|日志`~~ | **废**：面板已不存在 |

### 8.7 新增的已知限制

- **「完成后」动作不持久化**：重启回到「无动作」。这是全局运行策略，归 P6.2 运行设置一起落盘。

- **顶栏实例下拉不支持新建/删除**：只管切换，增删去「多实例」页。
