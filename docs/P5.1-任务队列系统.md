## 2. 数据层（Engine）

`src/MaaYys.Engine/Config/TaskSelection.cs`：新增
- `Id`：实例唯一标识，空串兼容旧数据；多实例时自动生成（Guid）。
- `Alias`：用户重命名；`DisplayName` 回退到 `Name`。
- `EnsureId()`：缺 Id 时补齐。

`src/MaaYys.Engine/Config/TaskConfiguration.cs`：新增
- `FindById(id)` / `AddInstance(name, alias?)` / `RemoveById(id)` / `MoveById(id, idx)` / `EnsureIds()`。
- `Validate()` 唯一键由 `Name` 改为 `Name#Id`，允许同类多实例。

`src/MaaYys.Engine/Config/ConfigurationStore.cs`：`Adopt` 加载后调 `EnsureIds()`，旧配置无 `id` 字段自动补齐，保证 `FindById` 始终有效（向后兼容）。

`src/MaaYys.Engine/TaskRunStatus.cs`：新增枚举 `None/Pending/Running/Done/Skipped/Failed/Stopped`。
